# Eksplorer SNBT-UTBK 2026

Alat eksplorasi interaktif untuk melihat **daya tampung** dan **jumlah peminat** seluruh program studi pada Seleksi Nasional Berdasarkan Tes (SNBT-UTBK) 2026. Dibuat agar calon mahasiswa, orangtua, dan pendidik dapat dengan cepat membandingkan tingkat keketatan antar prodi sebelum menentukan pilihan.

## Apa yang bisa dilakukan

- **Filter**: cari prodi berdasarkan provinsi, PTN, bidang ilmu, dan jenjang (Sarjana / Sarjana Terapan / dsb.).
- **Pencarian bebas**: ketik nama prodi atau universitas untuk pencarian instan.
- **Urutkan**: klik header kolom untuk mengurutkan berdasarkan daya tampung, peminat, atau rasio keketatan.
- **Ringkasan**: panel statistik menampilkan total prodi, jumlah PTN, total kursi, dan total peminat sesuai filter aktif.
- **Indikator keketatan**: tiap baris diberi label warna —
  - 🟢 longgar (rasio < 1:5)
  - 🟡 sedang (1:5 – 1:14)
  - 🔴 ketat (≥ 1:15)
  - ⚪ prodi baru (belum ada data peminat tahun sebelumnya)
- **Tautan langsung**: nama prodi terhubung ke laman penerimaan mahasiswa baru PTN masing-masing.

## Cakupan data

- **5.132** program studi
- Seluruh PTN peserta SNBT-UTBK 2026
- Daya tampung resmi UTBK-SNBT 2026
- Peminat berdasarkan data tahun 2025

## Sumber data

Data daya tampung berdasarkan UTBK-SNBT 2026. Peminat diambil dari data tahun 2025. Rasio dihitung dari peminat dibagi daya tampung. "Prodi baru" berarti belum ada data peminat sebelumnya. Data berasal dari Seleksi Nasional Penerimaan Mahasiswa Baru (SNPMB).
